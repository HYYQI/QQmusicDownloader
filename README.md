# QQ音乐下载器

基于QQ音乐接口的命令行音乐下载工具。支持关键词搜索、歌词下载、音频下载，并自动将 m4a/aac 转换为 mp3 格式。

## 功能

- 关键词搜索歌曲，展示歌名、歌手、专辑、时长及 VIP 标记
- 下载 LRC 格式歌词
- 下载音频（m4a/aac 格式）
- 自动调用 ffmpeg 转换为 mp3，转换后删除原始文件
- 所有输出文件统一命名为 `歌名-歌手` 格式
- 完整的日志记录（文件 + 控制台）

## 环境要求

- Python 3.8+
- ffmpeg（用于音频格式转换）

## 安装

### 1. 克隆项目

````bash
git clone <repo-url>
cd downloader
````

### 2. 创建虚拟环境并安装依赖

````bash
python3 -m venv .venv
source .venv/bin/activate    # Linux/macOS
# .venv\Scripts\activate     # Windows
pip install -r requirements.txt
````

### 3. 安装 ffmpeg

````bash
# Debian/Ubuntu
sudo apt install ffmpeg

# macOS
brew install ffmpeg

# Windows
# 从 https://ffmpeg.org/download.html 下载并添加到 PATH
````

> 不安装 ffmpeg 仍可下载原始 m4a/aac 音频，但无法自动转换为 mp3。

## 使用

````bash
source .venv/bin/activate
python main.py
````

### 交互流程

1. 输入搜索关键词
2. 查看搜索结果列表
3. 输入序号选择要下载的歌曲
4. 程序自动下载歌词和音频，并将音频转换为 mp3
5. 下载完成后可选择继续下载、重新搜索或退出

## VIP 歌曲说明

未登录状态下，部分 VIP 歌曲无法获取音频下载链接，程序会标记 `[VIP]` 并给出提示。如需下载 VIP 歌曲，可在以下文件中填写登录后的 Cookie：

- `api/search.py` 中的 `COOKIES`
- `api/audio.py` 中的 `COOKIES`

需要填写的关键字段：

````python
COOKIES = {
    "uin": "你的QQ号",
    "qqmusic_key": "你的登录key"
}
````
